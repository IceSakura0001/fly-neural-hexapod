# 第二阶段：MaleCNS 神经接入验收

日期：2026-10-21，Asia/Shanghai。部署地址：http://127.0.0.1:8765/ 。

**完成的是神经子网络到关节的因果接入和感觉反馈，不是完整脑复现，也不是稳定行走验收。**

## 实际部署

在原本机 Docker 控制台中增加默认的 MaleCNS 神经实验模式；人工 CPG 保留为显式对照。Windows / WSL 全局配置未调整，没有安装主机全局依赖。原 8848 服务保留，AGX Orin 未使用。

神经模式读取真实连接组上的 LIF 放电，经带限幅的肌群差分投影生成关节目标。没有调用 CPG 轨迹或推进 CPG 相位。停止和初始静态站姿由工程层保持。

## 因果对照

固定随机种子，给予相同下行刺激，关闭感觉输入以隔离因果路径：

- 正常连接：运动池出现放电，示例最高平均放电率约 49.8 Hz，记录到的最大目标偏移约 8.03°。
- 切断全部突触：指令神经元仍放电，运动池平均放电率为 0，所有关节目标偏移为 0。
- 切断运动读出：神经放电仍存在，关节目标偏移为 0。
- 相同随机种子及输入重放，目标轨迹逐元素相同。
- 模型权重在实验前后哈希一致，没有训练或修改权重来匹配动作。

改变身体输入后，感觉输入均值从静止的角度/速度/载荷 5/5/0 Hz，变为约 56.96/59.85/50 Hz。这里验证的是工程感觉编码确实读取身体变量，不是感觉神经元调谐的生物学有效性。

完整证据：`evidence/neural-causality.json`。

## 与用户 URDF 的联合测试

每次从相同状态开始，站立 1 s，再施加一种神经通路刺激 3 s：

| 刺激通路 | X 位移 | 航向角 | 末态最大目标偏移 | 引擎警告 |
|---|---:|---:|---:|---:|
| 前行相关下行群 | +4.35 mm | -1.04° | 3.50° | 0 |
| MDN | -7.35 mm | -0.13° | 4.41° | 0 |
| 左侧 DNa02 | -6.08 mm | +0.59° | 2.57° | 0 |
| 右侧 DNa02 | -8.29 mm | -0.58° | 2.81° | 0 |

这些结果证明神经输出在影响身体，**不能证明已形成可靠的前后/转向步态**。没有使用第一阶段 CPG 的约半米位移来作为神经控制性能。

候选版和正式部署均通过 HTTP / WebSocket 神经闭环测试；正式版关节目标偏移达到数度，感觉数据持续回传，CPG 相位保持为 0。网页实际键盘刺激、松键停止、模式切换、3D 视图、六腿放电轨迹和日志均检查，浏览器没有警告或错误。

原人工 CPG 的物理测试和四方向接口回归通过，心跳超时、断线停止、控制方互斥和跨来源拒绝保持有效。记录：`cpg-regression.json`、`cpg-live-regression.json`；正式神经测试：`neural-live-deployed.json`。
