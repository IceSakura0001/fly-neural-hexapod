# 动态接线映射 · 2026-10-22

本机首页新增“从神经活动，到机身动作”，展示移动意图代理、4 组下行 DN、MaleCNS/VNC 子网、36 个运动池、单标量使能、人工接触步序/逆解/伺服，以及六腿 18 关节和感觉反馈。

## 高亮来源

- 蓝色 DN、绿色 MN 节点：最近 100 ms 仿真累计脉冲差。池亮度 = 有脉冲时 0.35 + 0.65 × min(1, 脉冲数 / max(1, 池细胞数 × 1.5))；零脉冲不亮。Hz 是 LIF 指数平滑发放率。
- 流动线只表示该窗口有活动，不表示单脉冲的准确传导时刻或连接因果效应。分组连线不是直接突触清单，VNC 内多突触/递归网络以汇总框表示。
- 36 池汇入唯一 220 MN 的均值，然后经工程阈值压缩为 1 个使能值。没有绘制虚假的逐池独立关节驱动。
- 橙色为工程控制；关节亮度使用实际 qfrc_actuator 的 |扭矩| / 90 N·m 限幅至 1。站立承重仍有扭矩，不能当成神经放电。红色表示接近既有 450 N·m 扭矩上限。
- 足端触地状态来自物理反馈；感觉输入经过人工编码。中央脑未模拟，未添加解剖脑图或虚构细胞放电。

## 操作

按住 W/A/S/D 观察路径变化，松开停止。点击运动池、机身腿部或上方腿名追踪通路，其他腿变暗。池提示和详情展示实际脉冲、Hz、细胞数量和官方 bodyId。± 为既有关节投影符号，不代表已验证的生物拮抗肌作用。

“冻结画面”只冻结这张映射的状态和线条动画，物理仿真继续；显示冻结时刻，点击“跟随实时”恢复。窄屏可横向滚动图示。未连接时停止活动高亮；CPG/旧直接偏移模式明确提示当前 VNC 路径未使用。

控制来源审计里的切断/旁路状态同步到图中：突触断开变灰；切断运动读出时池仍可发放但到使能的连线断开；人工旁路独立以橙色显示用户到工程层路径；人工步序关闭时到机身的路径断开。旁路下 DN 可以因外部刺激发放，而 MN 为零；不把 DN 发光解释为 VNC 在控制步态。

## 数据和验证

`/api/neural/wiring` 给出分组、成员 ID、数据来源和解释；WebSocket 的 `neural.wiring_window` 给出窗口末时刻、时长、各 DN/池脉冲和唯一 MN 脉冲总数。控制步长、权重、随机种子、步序和伺服参数未改。

`tests/wiring_verify.py` 已验证 4 DN 分组、36 MN 池、220 个唯一 MN、705 感觉细胞、官方 ID 对应，连续 8 个 100 ms 窗口计数逐项相等，读取不改变仿真、复位清除旧高亮，以及断突触时 MN 零脉冲但外部 DN 可继续放电。结果见 evidence/wiring-telemetry-verification.json。

这是当前系统的软件功能映射和仿真活动可视化，不构成果蝇完整大脑控制的独立证据。
最终浏览器验收：36 池和18关节齐全；正常前进窗口157个MN脉冲，26池高亮，使能1，方向输入线为前进1/其余0；旁路前进159 mm时MN0脉冲、0池高亮、神经读出断开；冻结窗口停在13.6s而物理推进到23.1s，线条动画确实暂停；细胞详情和bodyId可展开，页面无控制台错误。最终版本六组物理对照全部通过，数据见 evidence/wiring-causal-audit.json。服务已恢复正常VNC待机，机身净空250mm、引擎警告0。
