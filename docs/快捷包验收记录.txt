快捷包验收 · 2026-10-23

环境：Windows 系统自带 Windows PowerShell 5.1、Docker Linux amd64。
验证范围：同一台电脑的独立中文/空格路径、独立 Compose 项目、独立新数据卷。未实测另一台同事电脑；Docker Desktop 初次安装由同事自行完成。

通过：
- 从离线 image.tar 重新导入发布标签，镜像 ID 与 release.json 一致。
- 启动不构建镜像、不拉取镜像、不安装依赖。
- 原项目占用8765时，快捷包自动选8766；重复启动仍复用8766与既有容器。
- 新角度卷正确初始化；修改角度、停止后重新启动，保存角度保持。
- 初始化服务未覆盖已有设置；状态/停止/故障诊断入口可用。
- 用户NBS模型、3D场景API、18路扭矩、4组DN/36运动池映射及神经数据完整。
- 前进仿真约3.3秒位移165 mm，运动池有实际仿真脉冲，警告0。
- 包内前端JS和CSS与运行镜像的构建内容SHA256逐项一致。
- 自带动态接线图、六组因果对照、可调默认角度、触地反馈与负载显示。
- 未打入个人配置、node_modules、本机Docker数据卷或临时启动日志。

运行时模型属于“连接组活动 + 工程步序”实验，不是完整果蝇大脑。
