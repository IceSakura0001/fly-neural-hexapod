# 实时扭矩与可保存默认角度

2026-10-22，本机 Docker / NBS V5 URDF / MuJoCo 3.8.0。

## 实时扭矩

六腿顺序：左前、左中、左后、右前、右中、右后。每腿顺序：髋、大腿、小腿。新增 `joint_torques_nm`，从实际 `qfrc_actuator` 对应自由度取得；带符号，单位 N·m。前端大字显示绝对值，小字显示方向，超过限幅的 90% 时标橙。当前传动比为 1，测试与 18 个对应执行器 `actuator_force` 全部一致。它不是 `ctrl`，不混入接触约束和被动力矩。

六边形静站时，大腿驱动力矩大小约 43–57 N·m，小腿约 11–16 N·m，髋接近零。动态读数会变化。450 N·m 上限沿用旧版假设，未进行实机标定。

## 默认角度

六腿的 18 个参考角可独立编辑。服务端根据候选角正向计算足端，再检查地面高度一致性及高度补偿范围中的逆解可达性，完整通过后才替换参考并复位。相对六边形预设 ±15°；足端球心高度极差 ≤30 mm，距理想接地高度偏差 ≤40 mm。验证范围不是原始 continuous URDF 未提供的机械限位。

保存值写入 Docker 命名卷，临时文件替换保证完整写入。普通重启和重建保留；无效输入不覆盖已有配置。复位/模式切换继续使用保存值，250 mm 高度补偿保留；自定义时界面不再标称足端正六边形。支持恢复预设并保存。

- `tests.controls_verify`：力矩来源与执行器一致；18 路有限、限幅正确；自定义角度精确应用，复位与模式切换沿用；自定义姿态静站净空 249.99956 mm；人工对照运行无物理警告；4 类无效输入拒绝且原配置不变；恢复预设通过。结果 `evidence/controls-physics.json`。
