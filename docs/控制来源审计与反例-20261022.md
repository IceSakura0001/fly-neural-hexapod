# 控制来源审计与反例 · 2026-10-22

## 结论

当前系统不能证明“果蝇大脑生成六足机器人步态”。正常行走依赖人工接触步序层；连接组 LIF 仿真的运动池活动只被压缩成使能标量，下行 DN 活动经过人工解码决定方向。中央脑没有模拟，VNC 连接组也没有直接输出各关节独立的时变肌群命令。

用户对“过于像人工控制”的怀疑得到旁路反例支持。此前把行走流畅度作为神经控制有效性的依据并不充分。

## 可重复对照

页面“控制来源审计”提供六组独立物理实验。各组同一个 MuJoCo 模型、当前参考姿态、随机种子 1729、6 秒预热、8 秒恒定前进意图；固定同一套既有 LIF 权重变换，无组间训练。实验在独立进程执行，不驱动正在查看的机器人。

首次验收结果（实际质心 X 位移）：

| 条件 | 前进位移 mm | 220 个映射 MN 的刺激期脉冲 | 推算 / 采用使能均值 | 落足总次数 |
|---|---:|---:|---:|---:|
| 正常神经使能 + 人工步序 | 438.0 | 13426 | 1 / 1 | 24 |
| 切断全部突触 | 约 0 | 0 | 0 / 0 | 0 |
| 切断运动神经读出 | 约 0 | 13298 | 0 / 0 | 0 |
| 人工旁路：突触断开、固定使能、直接意图方向 | 463.1 | 0 | 0 / 1 | 24 |

| 仅关闭神经感觉输入 | 439.3 | 12786 | 1 / 1 | 24 |

全部条件引擎警告为 0，无安全锁止。“切断后停止”只能证明人工使能联锁生效。“人工旁路仍走”证明现有工程层无需运动池活动即可生成行走。仅关闭神经感觉输入仍走，说明这组平地任务未证明神经感觉通路对行走必需。神经活动确实进入正常模式的使能和方向读出，但上述事实不足以证明神经网络生成步序、自然运动或完整脑控制。

## 页面核验

- 六组反例实验：位移柱图、实际位移时间序列、脉冲/使能/落足对照；可重新运行、下载原始 JSON。
- 实时信号与现场干预：模型运动池平均放电、推算与工程采用的使能、机身速度；可切断突触、切断读出、启用人工旁路、关闭步序或神经感觉输入。每次切换停止并复位场景。
- 脉冲栅格来自 16 个 DN 和 12 个 MN 的实际 LIF 累计脉冲差，约 100 ms 一箱。展示真实连接组 bodyId；是仿真脉冲计数，不是活体记录、精确脉冲时刻或解剖脑图。抽样栅格不代表全部 24071 个细胞。
- 人工旁路状态用醒目标记提示。未绘制虚构的“脑区发光”或将目标角曲线当神经证据。
- 原始接口：`/api/causal/trace`、`/api/causal/audit`、`/api/causal/report.json`。后者包含参数、来源校验值、每组轨迹和完整性检查。重启服务会清除内存中的报告，下载文件可保留证据；角度设置仍由原数据卷持久保存。

## 权重与证据边界

处理后权重 SHA256：`2f547b0a84d24869e6a2a142a8437ffbb668cd47c1966595af3d72fefcbe61f2`。这不是未变换的原始突触计数；既有处理包括符号、60 上限、同类型 0.1、DN→VNC 3 倍、输入归一化、总增益 0.275。原始数据来源指纹随报告输出。

这次新增的是审计和明确标记的实验干预，没有将工程步序冒充神经输出。后续若要主张神经网络生成步态，需在固定、非步序性的身体适配层下，由神经输出决定逐腿逐肌群的时序和幅值，并通过置乱、延迟、替代神经输出及感觉反馈任务的预注册对照证明因果贡献。现有数据尚未达到该标准。
