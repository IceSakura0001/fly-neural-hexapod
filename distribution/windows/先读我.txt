六足机器人神经仿真实验台 · 快捷离线版 2026.10.23

三步启动
1. 同事的电脑需是 Windows 10/11 64 位（x64），安装好 Docker Desktop，并完成 WSL2 / Linux 容器的首次设置。
2. 将整个 ZIP 解压到可写文件夹，例如 D:\Hexapod。不要只从压缩包里打开某一个文件。
3. 双击“启动.cmd”。首次会校验并导入离线镜像、编译神经内核；成功后自动打开浏览器。

不用另装 Python、Node、MuJoCo，不用下载神经数据，也不需要 AGX Orin 或 NVIDIA 显卡。
Docker 已安装并能启动 Linux 引擎后，本包可以离线运行。Docker Desktop 的安装、WSL2 系统组件安装不属于本包。

运行条件
- 建议电脑内存 16 GB；Docker 引擎至少分配约 5 GB，本应用默认限额 4 GB / 2 CPU。
- 解压、导入镜像和运行建议预留 8 GB 磁盘空间；浏览器需能启用 WebGL。
- 这是 Linux amd64 离线镜像；未针对 Mac、ARM64 或 Windows 容器模式验证。

网页与操作
- 默认 http://127.0.0.1:8765/ 。如果被其他程序占用，启动器依次尝试后续20个端口，最终地址会打印并自动打开。
- 启动成功后的地址也保存在 .runtime/last-url.txt。
- 按住 W/A/S/D 或页面方向按钮；松开停止，空格停止，断线/失去焦点有停止保护。
- 首页动态图显示4组DN、36运动池、单标量使能、人工步序、六腿18关节实际扭矩及身体反馈。
- 选择腿或运动池追踪路径、查看细胞编号；“冻结画面”只冻结图示，物理仿真继续。
- 页面可编辑18个默认角度，保存后复位、模式切换、正常重启均保留。初始姿态沿用打包时的六边形预设，机身目标净空250 mm。
- “六组反例实验”需要在同事电脑上点击重新运行。docs 内的报告是原机历史验收数据，不是同事本机的现场结果。

停止、重开与诊断
- 双击“停止.cmd”仅停止这个快捷包，保留保存的角度。
- 再双击“启动.cmd”复用已有镜像，不重复下载或导入。
- “运行状态.cmd”显示容器状态；“故障诊断.cmd”将最近日志保存到 diagnostics 文件夹。
- 启动失败时把 diagnostics/launcher.log 和 diagnostics/containers.log 发给项目维护者。
- “Docker Linux engine is not ready”：先在 Docker Desktop 完成首次设置，等到引擎运行后再启动。
- “Offline image checksum does not match”：重新复制/完整解压本包。
- 端口或资源需求可在 settings.env 调整。已运行实例重启时会优先复用自己的端口。
- 本包使用独立项目名 hexapod-share-20261023 和独立角度数据卷，不会复用原项目的容器/数据卷。移动包的位置后先停止再重开即可；只读共享盘请先复制到本地可写目录。

包内内容
- runtime/image.tar：含全部运行依赖、模型、神经数据和构建后的网页的离线镜像。
- defaults：首次初始化角度；之后的自定义角度保存在 Docker 命名数据卷。
- source：Python 后端、React/Three.js 源码、已构建网页、模型、处理后的 MaleCNS 子网和验证脚本；不含 node_modules、缓存、个人配置或原始完整连接组。
- docs：控制来源说明、动态接线说明与原机验收记录。
- release.json / CHECKSUMS.sha256：镜像版本、校验值和文件校验清单。
- THIRD_PARTY_NOTICES.md / licenses：来源与许可证声明；Python依赖及基础系统的许可也保留在离线镜像内部。

实验范围
当前是 MaleCNS 下行/VNC 连接组的简化LIF仿真与工程运动接口，不是完整果蝇大脑。36个运动池在VNC模式下汇总为一个使能值，步序由人工接触规则、逆解和伺服产生。神经高亮来自实际仿真脉冲，关节高亮来自实际驱动扭矩；高亮本身不能证明大脑生成步态。详情见 docs。

内部修改（可选）
日常运行不需要 source 里的依赖安装。需要修改时可用 source/Dockerfile 重新构建镜像；重新构建通常需要网络下载基础镜像和依赖。快捷启动始终使用release.json校验的发布版，不会默默改用自建镜像。
